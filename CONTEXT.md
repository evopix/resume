# Resume

Personal resume built with Typst. Single context.

## Language

**Hardened workflow**:
A workflow with least-privilege `GITHUB_TOKEN` permissions, SHA-pinned `uses:`, and no script injection.
_Avoid_: secured, locked-down workflow

**Action lint**:
Static checks for workflows: `actionlint` for correctness, `zizmor` for security.
_Avoid_: action linter, workflow lint
